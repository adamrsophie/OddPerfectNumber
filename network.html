The valuation network

Perfection, σ(N) = 2N, can be read prime by prime. The result is a weighted directed graph on the prime factors of N with an exact conservation law at every vertex. The library proves that the conjecture is equivalent to the statement that no finite graph of this kind balances.

Nodes and weights

The nodes are the prime power components pep of N, where ep is the exact exponent of p. The weight of the edge from p to a prime r is the r-adic valuation of the component divisor sum:

w(p, r) = vr(σ(pep))

So p sends to r as many factors of r as σ(pep) contains. There is an edge p → r between prime factors exactly when this weight is nonzero.

def sigmaWeight (N p q : ℕ) : ℕ := (σ 1 (p ^ N.factorization p)).factorization q

From OddPerfect/Network.lean

def SigmaEdge (N p q : ℕ) : Prop :=
  p ∈ N.primeFactors ∧ q ∈ N.primeFactors ∧ q ∣ σ 1 (p ^ N.factorization p)

From OddPerfect/Network.lean

Conservation

Since σ is multiplicative, σ(N) is the product of the component sums, so vr(σ(N)) is the sum of the weights into r. Comparing with vr(2N) gives one exact equation per prime:

  • for every odd prime r, the incoming weights add up to er, the exponent of r in N (zero if r does not divide N);
  • at r = 2 the incoming weights add up to exactly 1, because N is odd and 2N has a single factor 2.

Two further facts: no prime divides its own component sum, since σ(pe) ≡ 1 (mod p), so there are no self loops; and no weight leaves the prime factors of N except the single unit into 2, by the forcing step.

theorem sigmaWeight_sum_eq {N q : ℕ} (hN : N.Perfect) (hq : q.Prime) (hq2 : q ≠ 2) :
  ∑ p ∈ N.primeFactors, sigmaWeight N p q = N.factorization q

OddPerfect.sigmaWeight_sum_eq in OddPerfect.Network

theorem sigmaWeight_sum_two {N : ℕ} (h : OddPerfect N) :
  ∑ p ∈ N.primeFactors, sigmaWeight N p 2 = 1

OddPerfect.sigmaWeight_sum_two in OddPerfect.Network

The 2-adic equation is already strong: it is how the library proves Euler's form. The special prime q is the unique node sending weight to 2, and it sends exactly 1.

Strong connectivity

Every prime factor of N reaches every other along edges. The proof uses a cut lemma for any perfect number: if N = ab with a, b > 1 coprime, some prime of a divides σ(b). Otherwise a would divide σ(a), so σ(a) ≥ 2a, and σ(a)σ(b) ≥ 2aσ(b) > 2ab, contradicting σ(a)σ(b) = 2ab. Given a nonempty proper set S of prime factors, take a to be the part of N over S and b the rest: some component outside S sends an edge into S. Applied to the set of primes that reach a fixed prime q, this shows that the set cannot be proper, so everything reaches q.

theorem sigmaEdge_reflTransGen {N : ℕ} (hN : N.Perfect) {p q : ℕ}
  (hp : p ∈ N.primeFactors) (hq : q ∈ N.primeFactors) :
  Relation.ReflTransGen (SigmaEdge N) p q

Candidates and balance

To state the reformulation, the library forgets N and keeps only an exponent function. A Candidate is a finitely supported function p ↦ ep from the natural numbers to the natural numbers. Its support is the set where ep > 0, its value is ∏ pep, and its weights are defined exactly as above from σ(pep).

structure Candidate where
  exponent : ℕ →₀ ℕ

From OddPerfect/Reduction.lean

A candidate is Balanced when four local conditions hold:

  1. every element of the support is prime;
  2. 2 is not in the support;
  3. for every odd prime q, the weights into q from the support add up to eq; for a prime outside the support this says they add up to 0;
  4. the weights into 2 add up to exactly 1.
structure Balanced (C : Candidate) : Prop where
  /-- Every element of the support is prime. -/
  prime : ∀ p ∈ C.support, p.Prime
  /-- No element of the support is 2. -/
  ne_two : ∀ p ∈ C.support, p ≠ 2
  /-- Conservation at every odd prime. -/
  balance_odd : ∀ q : ℕ, q.Prime → q ≠ 2 → ∑ p ∈ C.support, C.weight p q = C.exponent q
  /-- The weights into 2 add up to exactly one. -/
  balance_two : ∑ p ∈ C.support, C.weight p 2 = 1

From OddPerfect/Reduction.lean

Note what is not in the definition: strong connectivity, Euler's form and other properties are consequences of balance, collected in the structure Candidate.Necessary and proved for every balanced candidate by Balanced.necessary. Candidate.Necessary is not a weaker problem. Its Touchard field makes the value odd and positive, and its field abundancy_eq_two makes that value perfect, so it follows from the fields that a candidate satisfying Candidate.Necessary exists if and only if an odd perfect number exists.

The reduction

theorem conjecture_iff_no_balanced : OddPerfectConjecture ↔ ¬ ∃ C : Candidate, C.Balanced

OddPerfect.conjecture_iff_no_balanced in OddPerfect.Reduction

Proof idea. An odd perfect number gives a balanced candidate: its own factorization, by the conservation laws above. Conversely, for a balanced candidate, compare the exponent of each prime q in σ(value) and in 2·value. Multiplicativity turns the first into the sum of the weights into q; balance makes that equal to eq for odd q and to 1 for q = 2, which is the exponent of q in 2·value; at a non prime both sides are 0. Two numbers with the same factorization are equal, so σ(value) = 2·value, and the value is odd because 2 is not in the support.

This is a reformulation, not progress toward a proof. The open problem is exactly whether a balanced candidate exists. Nothing in the library decides that, and nothing assumes the conjecture.

Example: the network of a spoof

No odd perfect number is known, so the picture below uses the Descartes spoof 3²·7²·11²·13²·22021, which is not an odd perfect number. Its formal divisor sums are σ(3²) = 13, σ(7²) = 57 = 3·19, σ(11²) = 133 = 7·19, σ(13²) = 183 = 3·61, and, treating 22021 as prime, 1 + 22021 = 22022 = 2·7·11²·13.

Reading off the weights: 3 receives 1 from 7² and 1 from 13², total 2; 7 receives 1 from 11² and 1 from 22021, total 2; 11 receives 2 from 22021; 13 receives 1 from 3² and 1 from 22021, total 2; and 2 receives exactly 1, from 22021, which plays the role of the special prime (22021 ≡ 1 mod 4, exponent 1). The bookkeeping balances only because the factors 19, 19 and 61, which are not nodes, are absorbed by the fake node 22021 = 19²·61. For a genuine balanced candidate every node must be prime, and this is where the spoof fails.

All numbers above were recomputed with exact integer arithmetic. The library records this example in Spoof, including formal conservation at every prime (valuation_balance_descartes).
